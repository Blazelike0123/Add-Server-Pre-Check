## Checks before you add server

Add Server Precheck is a lightweight, client-side Minecraft mod that checks whether a server is reachable before adding it to your multiplayer server list. If the connection fails, it displays an error message so you know what went wrong.

# Features

- **Server Pre-checking**: Check a server before adding it to your server list.

- **Error Messages**: See why a connection attempt failed.

- **Vanilla-Style Interface**: A clean interface that fits Minecraft's original design.

- **Loading Animation**: A simple three-dot animation while the server is being checked.

- **Add Anyway**: Choose to add the server even when the connection check fails.
  
- **Go back**: Edit or return to server list.
